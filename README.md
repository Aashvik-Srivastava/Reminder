# Reminder App ⏰

A simple Python reminder application that allows users to add, view, delete, and check reminders using date and time.

## 🚀 Features
- Add reminders with date & time
- View saved reminders
- Delete reminders
- Automatic reminder checker
- Stores reminders in a text file

## 🛠️ Tech Stack
- Python
- Datetime Module
- Time Module
- File Handling

## ▶️ Run Project

```bash
python main.py
```

## ⚙️ How It Works

Add reminder → Saved in file → Reminder checker runs → Alerts user at scheduled time

## 📂 Storage
Reminders are stored locally in:

```bash
reminder.txt
```
